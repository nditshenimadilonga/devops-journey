# Section 3 — The Command Line

**Status:** Planned
**VMs:** ubuntu-01, suse-01

## What I practise in this section

I practise working at the shell: shell variables and aliases, moving around and listing the file system, creating, copying, moving and deleting files, reading file contents, running commands in sequence, redirecting and piping output, and finding files.

## Before I start

Ubuntu may need a few tools installed first (for example `tree`).
