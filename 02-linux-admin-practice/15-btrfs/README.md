# Section 15 — Btrfs Management

**Status:** Planned
**VMs:** ubuntu-01, suse-01

## What I practise in this section

I practise the Btrfs file system that SUSE uses by default: creating file systems and subvolumes, exploring them, setting the default subvolume, and taking and rolling back snapshots with Snapper.

## Before I start

This section is SUSE only because it relies on SUSE's Btrfs setup and Snapper.
