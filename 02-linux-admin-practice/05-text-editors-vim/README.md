# Section 5 — Text Editors (Vim)

**Status:** Planned
**VMs:** ubuntu-01, suse-01

## What I practise in this section

I get comfortable editing files in Vim: the basics, customising it, copy and paste, search and replace, undo, visual mode, working with several files and comparing files with `vimdiff`.

## Before I start

Ubuntu may need the full `vim` package installed.
